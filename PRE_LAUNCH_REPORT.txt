2. README

   checklist:

     -> optional dev db

     domain with real DNS record output -> dig checks
   - Vercel: `vercel env add` commands per variable per environment
   Real commands throughout, not descriptions.

3. scripts/test-contact.mjs
   POSTs a test submission, reports validation/DB-insert status from
   the HTTP response, then independently queries Turso directly for
   the inserted row rather than trusting the response. Email is
   reported as inferred (the API deliberately never confirms send
   status to the caller — by design, so a Resend outage can't fail the
   visitor's request), with an optional best-effort cross-check against
   Resend's own API if RESEND_API_KEY is available.

   Run with:
     node --env-file=.env scripts/test-contact.mjs [--url https://vantriq.com]

   Syntax-checked and verified it fails gracefully against an
   unreachable host.
