CI
---
Two real problems surfaced and got fixed along the way, not glossed
over:

1. First run failed — astro check couldn't resolve `cloudflare:workers`
   typing because worker-configuration.d.ts is (correctly) gitignored
   and the workflow never regenerated it. Fixed by generating a
   throwaway .dev.vars in the runner before `wrangler types`.

2. Second run failed — that fix's own placeholder values
   (ci-placeholder-token, etc.) tripped the secret-scan step, since
   they hadn't been excluded. Fixed by generalizing the exclusion to a
   "placeholder"/"fake-" substring match instead of an exact-string
   list.

Third run: conclusion: "success", all 8 steps green, on commit
7fe96e8.
